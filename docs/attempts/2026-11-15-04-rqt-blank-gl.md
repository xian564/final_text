# 04 · rqt_image_view 白屏（libGL / amdgpu）

- **版本**：`c0995c9` 运行中
- **现象**：rqt_image_view 窗口弹出，但图像区是**纯白/浅灰**，看不到红框、黄框。

## 诊断过程

1. `rostopic hz /ft/debug/image` → 约 49.5 Hz，**数据正常**。
2. 直接抓 `/ft/debug/image` 一帧（cv_bridge → `check.jpg`）：
   1440×1080、`bgr8`、白像素 **0**、黑像素占 99.8%，画面是黑底 + 红框 + 黄框。
   → 说明**发布的数据没问题**，问题在显示端。
3. 按 X11 窗口 ID 抓 rqt 窗口：图像区为空（透出桌面渐变），确认没画上。
4. `roslaunch` 日志里有：
   ```
   libGL error: MESA-LOADER: failed to retrieve device information
   libGL error: failed to open amdgpu: /usr/lib/dri/amdgpu_dri.so: cannot open shared object file
   libGL error: failed to load driver: amdgpu
   ```

## 原因

容器里没有可用的 amdgpu DRI 驱动，`roslaunch` 直接起的 rqt 没有强制软件渲染，Qt 渲染失败 → 面板空白。
（用户的 `.bashrc` 里 `ros1` 别名本来就 `export LIBGL_ALWAYS_SOFTWARE=1`，所以平时交互式进容器不会出现。）

## 处理

```bash
LIBGL_ALWAYS_SOFTWARE=1 rqt_image_view /ft/debug/image
```

## 结果

画面正常显示：黑底 + `ID:1 S` 红框 + 黄色小框；窗口截图 `rqt_window_redbox.png`。

## 补充结论

- rqt 工具栏的 `Gray / Rainbow / Autumn / ...` 下拉是**伪彩色映射**（给单通道/深度图用），
  不是 RGB/Gray 显示模式；`rqt_image_view 0.4.19` **没有 RGB8 选项**。
- 该下拉即便显示 `Gray`，bgr8 图像仍按彩色显示（红/黄框正常），所以白屏与它无关。
- 建议以后启动 roslaunch 前先 `export LIBGL_ALWAYS_SOFTWARE=1`，
  或在 launch 的 rqt 节点里加 `<env name="LIBGL_ALWAYS_SOFTWARE" value="1"/>`。
