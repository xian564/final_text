目的：每次出错都能追溯到「哪个版本、什么命令、什么报错、怎么处理、结果如何」。

## 约定

- 每次尝试一个文件，命名：`YYYY-MM-DD-NN-主题.md`
- 每个文件必须包含：**版本/提交、命令、报错原文、原因、处理、结果、遗留**
- 本 README 维护索引；新记录追加到表格末尾
