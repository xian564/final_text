## 模块 6：FCS 残影重捕（新增）

触发条件：
1. 上一帧有成功目标（`prev_had_target_`）；
2. 当前帧没有配对成功（进入 `targets.empty()` 分支）；
3. 当前帧灯条数 `bars.size() <= 2`；
4. 距上一帧 < 1.0s。

候选搜索：
```cpp
cv::approxPolyDP(contour, poly, 0.02*arcLength, true);
if (poly.size() != 4) continue;                       // 四边形
asp = max(w,h)/min(w,h);
ok_armor = asp ∈ [0.5,1.8] × prev_armor_ratio;        // 符合上一帧装甲
ok_bar   = asp ∈ [0.6,1.6] × prev_bar_ratio;          // 或符合灯条
if (!ok_armor && !ok_bar) continue;
dist(candidate, prev_center) <= 300px;                // 历史位置范围
```

亮度梯度相似度：
```cpp
grad = mean(V 内部) - mean(V 边缘环);
if (|grad - prev_grad| > 45) continue;
```

补位动作：
- 用黄色**虚线框**框住候选；
- 画面文字 `[FCS] LOCK ID:x L/S`；
- 日志 `[FCS] 遮挡补位中 id=... L/S`；
- 继承上一帧 ID 与大小板属性，`lost_frames_ = 0`。

## 实测

- 25 秒运行：`ok=723`、检测 24 次、异常 0
- FCS 在测试中出现过（日志 `[FCS] ??? id=1 L`），但不是每轮都有：这段 bag 里“有残影且灯条≤2”的时刻很少
- 为确认各阶段条件，曾加过临时诊断：`bars=2 quad=2 asp=1 pos=1 grad=1` → 最终成功补位一次
